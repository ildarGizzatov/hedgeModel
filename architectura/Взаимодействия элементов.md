
Когда ты **дома**, всё работает исключительно через локальную сеть:

- MacBook → обычный PC — LAN
- обычный PC → GPU PC — LAN
- MacBook → GPU PC — LAN при необходимости
- обычный PC → PostgreSQL — `localhost`
- обычный PC → интернет — через роутер
- GPU PC → интернет — через роутер

Tailscale для этого не нужен.

| Устройство     | IP              | Подключение |
| -------------- | --------------- | ----------- |
| Роутер         | `192.168.0.1`   | —           |
| Обычный Ubuntu | `192.168.0.100` | Ethernet    |
| GPU-компьютер  | `192.168.0.103` | Wi-Fi       |
